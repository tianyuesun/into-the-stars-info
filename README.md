# Into the Stars 入梦星空

The info page for Into the Stars, a game about the few minutes before sleep.

- Page: https://angelasun-forward.vercel.app/into-the-stars
- Ten Dreams private alpha: https://into-the-stars-game-alpha.vercel.app/

I am independently designing Into the Stars, and all of its core gameplay mechanics are my own. I first built it in Godot 4.7.2, with AI-assisted coding throughout. The current Ten Dreams private alpha is implemented in HTML and JavaScript for browser-based playtesting. The full game is aiming for a public release in 2027.

## What the page shows

- The game's opening lines and three screens from the alpha
- The game's assets by category: dream tools, collectibles, creatures and guardians
- The ten dreams of the first chapter, and the shared star atlas with the twelve signs
- A preview of Deep Dream, the full game still in development
- How the game is made

## Files

- `index.html`: the whole page, with an English and Chinese switch
- `img/`: the game's art, screenshots and assets. Each screenshot has an English and a Chinese version, and the page swaps them with the language switch.

## Updating the alpha link

The link lives in one place: `ALPHA_URL` near the end of `index.html`. Both cloud buttons use it. Leave it empty and the buttons read "Ten Dreams alpha opening soon".

The star lines and floating assets stay still for visitors who set their device to reduce motion.

## 入梦星空

一款关于入睡前那几分钟的游戏，这是它的介绍页面。

- 页面：https://angelasun-forward.vercel.app/into-the-stars
- 十梦邀请制内测：https://into-the-stars-game-alpha.vercel.app/

《入梦星空》由我独立设计，所有核心玩法与游戏机制均为原创。游戏最初在 Godot 4.7.2 中开发，全程借助 AI 辅助编程。目前开放的「十梦」邀请制内测是用 HTML/JavaScript 实现的浏览器试玩版。完整版目标是 2027 年正式上线。

## 页面内容

- 游戏开场诗和三张内测画面
- 按类别展示的游戏素材：道具、收集、小怪、守护者
- 第一篇章十梦的十个梦境，以及共享的星图和十二星座
- 深梦预告：仍在制作中的完整游戏
- 游戏是怎么做出来的

## 文件

- `index.html`：整个页面，可切换中英文
- `img/`：游戏美术、截图和素材。每张截图都有中英文两版，随语言切换。

## 更新内测链接

链接只写在一处：`index.html` 末尾的 `ALPHA_URL`，两个云朵按钮共用。留空时，按钮会显示“十梦内测即将开放”。

设备开启了“减少动态效果”的访客，看到的星光线和素材都是静止的。
